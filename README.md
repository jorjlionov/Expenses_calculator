# 💰 Expenses Calculator (Telegram Bot)


![Telegram](https://img.shields.io/badge/Telegram-Bot-0088cc?logo=telegram)
![Database](https://img.shields.io/badge/DB-SQLite3-lightgrey?logo=sqlite)
![License](https://img.shields.io/badge/License-MIT-green)

> Современный асинхронный Telegram-бот для ведения личной финансовой статистики. Контролируйте свои доходы и расходы, получайте аналитику с графиками и экспортируйте данные в Excel прямо в любимом мессенджере! 📊

## ✨ Возможности

- 🏦 **Учёт операций** — добавление доходов и расходов с привязкой к категориям
- 📅 **Автоматическая фиксация** — каждая транзакция автоматически сохраняется с актуальной датой и временем
- 📈 **Аналитика и отчёты** — генерация подробных финансовых сводок за текущий месяц или за всё время использования
- 📊 **Визуальные графики** — наглядное отображение доходов и расходов в виде графиков для быстрого анализа
- 📥 **Экспорт в Excel** — выгрузка всех финансовых данных в удобный Excel-файл для дальнейшего анализа
- 💵 **Визуализация** — понятные отчеты с использованием эмодзи для быстрого восприятия информации
- 🔒 **Приватность** — все ваши финансовые данные надежно хранятся локально в базе SQLite
- ⚡ **Высокая производительность** — полная асинхронность обеспечивает молниеносную работу даже при большом количестве операций

## 🛠 Технологический стек

- **Язык**: Python 3.9+
- **Telegram API**: `aiogram 3.x` (асинхронный фреймворк для работы с Telegram Bot API)
- **База данных**: `SQLite3` + `aiosqlite` (асинхронная работа с БД)
- **Графики**: `matplotlib` (визуализация финансовых данных)
- **Экспорт**: `openpyxl` (генерация Excel-файлов)
- **Конфигурация**: `python-dotenv` (безопасное хранение секретов)

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/jorjlionov/Expenses_calculator.git
cd Expenses_calculator
```

### 2. Настройка окружения
Создайте файл .env в корневой директории проекта и добавьте туда токен вашего Telegram-бота (получить его можно у @BotFather):

```env
TELEGRAM_TOKEN=ваш_секретный_токен_от_botfather
DB_PATH=путь_или_название_вашего_файла_Базы_Данных
```

### 3. Установка зависимостей
Рекомендуется использовать виртуальное окружение Python:

```bash
# Создание виртуального окружения
python -m venv venv

# Активация виртуального окружения
# Для Windows:
venv\Scripts\activate

# Для Linux/macOS:
source venv/bin/activate

# Установка всех необходимых библиотек
pip install -r requirements.txt
```

### 4. Запуск бота

```bash
python main.py
```

Бот запустится в асинхронном режиме и будет готов к работе! 🚀

## 📱 Как пользоваться

**1** Найдите бота в Telegram и нажмите Start (или отправьте команду start)
**2** Следуйте подсказкам бота для добавления новых транзакций, используя Inline меню
- 📊 **Графики** — визуализация доходов и расходов
- 📥 **Экспорт** — выгрузка данных в Excel
- 📈 **Отчёты** — детализация за месяц/год/всё время

**3** Следите за своими финансами и достигайте целей! 🎯
